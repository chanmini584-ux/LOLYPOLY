# 학교 버스 (노선 줄그림 + 실시간 위치) 설계

- v1 (2026-11-05): PDF 노선도만 손으로 옮기는 정적 화면 — 사용자 시안 승인
- **v2 (2026-11-07, 현재)**: 사용자 지시 "시안의 노선표 위에서 버스 모양이 실시간으로 움직이며 현재 위치를 알려 주는 기능을, 묻지 말고 끝까지" → TAGO API 실시간으로 확장
- 관련 결정: D-040(데이터 출처), D-041(실시간 호출 예외), D-006(하단 탭 5개), D-037(플래너 디자인)

## 1. 결승선

홈 바로가기 "학교 버스" → `/bus/`에서 노선 번호 탭을 고르면, 학교 정류장 앞 구간 줄그림 위에
지금 운행 중인 버스 아이콘이 30초마다 갱신되며 정류장을 따라 움직이고 "N정거장 전"을 알려 준다.

## 2. 확인한 사실 (2026-11-07 실제 TAGO 호출)

- 춘천 cityCode = 32010. 공공데이터포털 TAGO 4종(노선·위치·정류소·도착) 활용 승인된 키로 호출 성공.
- '폴리텍' 정류소: 폴리텍대학 2곳(CCB250001951 시내→동산면, CCB250001952 동산면→시내), 폴리텍입구(CCB265000762, 동산면→시내), 폴리텍2캠퍼스 2곳(후평동 쪽, 제외).
- 폴리텍대학을 지나는 노선: 901, 동산1~5, 남산2-1 (변형 포함 routeId 18개). 폴리텍입구는 901·동산1·동산3 (PDF와 일치).
- 노선 하나(routeId) = 왕복 전체 정류장(nodeord 순, updowncd 0/1). 901은 149개.
- 같은 번호의 변형: `901(기점군자리)`, `동산1(동산102)` 등 → 번호(괄호 앞)로 묶어 탭 하나.
- 08시 실제 확인: 마을버스 포함 실시간 위치 제공, nodeord 정수. 한 버스는 학교에 먼저 닿는 칸 하나에만 표시.
- 호출 약 10번 중 1~2번 연결 끊김 → 재시도 필요.

## 3. 구조

```
[수집] collect_bus (TAGO, 주 1회·서버 시작 시 비어 있으면)
  학교 정류장 3곳 → 경유 노선 → 노선별 정류장 → 검증 → BusRoute/BusRouteStop 원자적 교체 → CollectionRun(bus)
[화면] /bus/?route=901  → DB만 읽어 줄그림(칸 2개) + 운행 시각(PDF) 렌더링
[실시간] bus.js → /bus/live/901/ (30초) → 서버 캐시 30초 → TAGO 노선별 버스 위치(변형마다 1회)
          → 버스의 nodeord 를 그 변형 정류장 목록에서 찾아 칸 안 위치(pos)·학교까지 남은 정류장(away)로 변환
```

| 파일 | 역할 |
|---|---|
| `campus/tago.py` | TAGO 호출(재시도·오류 구분: 키 없음/한도 초과/기타), 키는 오류 메시지에 남기지 않음 |
| `campus/collectors/bus.py` | 학교 정류장 ID, 노선 수집·검증·저장 |
| `campus/bus.py` | 탭 목록, 칸(학교 가는 버스 / 시내 가는 버스) 구간, 버스 위치 변환, 캐시·심야·실패 처리 |
| `campus/bus_timetable.py` | PDF 운행 시각(기점/종점 출발) |
| `templates/campus/bus.html`, `static/js/bus.js`, `static/css/app.css` | 줄그림, 움직이는 버스 아이콘 |

## 4. 화면 규칙

- 칸 = 학교 정류장 기준 방향. **학교 가는 버스**(시내 → 폴리텍대학), **시내 가는 버스**(폴리텍대학·폴리텍입구 → 시내).
- 각 칸은 학교 정류장 앞 8개 ~ 학교 정류장 다음 1개. 위아래 점선 = 노선이 이어짐.
- 학교 정류장: 빨간 동그라미 + 형광펜. 버스 아이콘: 파란 원, 학교 정류장에 있으면 빨간 원.
- 버스 표시: "N정거장 전" / "학교 정류장" / "지나감". 칸보다 먼 버스는 칸 아래 "더 먼 곳에서 오는 버스: ○○ 부근(N정거장 전)".
- 같은 차량은 같은 아이콘이 0.9초 동안 미끄러져 이동(움직임 줄이기 설정이면 즉시 이동).
- 상태 문구: "14:05:12 기준 · 30초마다 갱신", 버스 없음, 심야, 키 없음, 한도 초과, 지연(직전 위치) 구분.
- 운행 시각: PDF 기준, "기점·종점 출발 시각이에요. 학교 정류장 도착 시각이 아니에요." + 출처·쪽 번호.
- 스크린리더: 칸마다 요약 문장(aria-live polite), 학교 정류장에 "(우리 학교 정류장)".

## 5. 한계

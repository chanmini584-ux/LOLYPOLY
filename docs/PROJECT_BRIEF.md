# Lolypoly 프로젝트 개요

## 목표

한국폴리텍대학 춘천캠퍼스 공식 홈페이지에 흩어진 **공개 생활정보**(식단·학사일정·공지)를
로그인 없이 스마트폰에서 빠르게 확인할 수 있도록 모은 모바일 웹 프로토타입.

산출물 우선순위:
1. 실제 조작 가능한 모바일 웹 프로토타입 ← **현재 집중**
2. 구현 내용과 검증 결과에 근거한 기획서 (프로토타입 검증 이후)
3. 학교에 제시할 개선 제안서 (프로토타입 검증 이후)

## 대상

- 한국폴리텍대학 춘천캠퍼스 학생 (잠재 이용자 약 300명 — 동시 접속자 수가 아님)

## 화면

- 홈: 오늘 날짜, 오늘/이번 주 식단, 가까운 학사일정, 최신 공지, 주요 메뉴
- 식단: 날짜·요일 선택, 조식/중식/석식, 마지막 수집 시각, 공식 원문
- 학사일정: 가까운 일정과 월별 목록, 공식 원문
- 공지: 제목·날짜·분류·원문 링크
- 시간표: 예시 시간표와 오늘 수업 (Mock)
- MY: 프로토타입 안내와 향후 기능 설명 (Mock)

## 확정된 제약

- 기술: Python, Django + Django Template, HTML/CSS/최소 JS, Python Playwright, SQLite(개발·잠정)
- 이후 운영: Ubuntu Server, Nginx, Gunicorn, Git (단일 PC)
- 화면 요청 시 공식 홈페이지를 실시간 수집하지 않는다 (DB 조회만)
- 자동 갱신 기본 주 1회, 종류별 주기 변경 가능
- 시간대 Asia/Seoul
- 로그인 우회·접근 제한 우회 금지

## 개발 단계와 완료 기준

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1. 프로젝트 기반 구축 | 기준 문서, Django 프로젝트, Custom User, 6개 경로, 공통 모바일 레이아웃, 실행 파일 | 새 환경에서 안내대로 설치·마이그레이션·실행 가능, 기본 검사와 6개 화면 응답 통과 |
| 2. 모바일 UI Mock | 화면을 실제 조작 가능한 수준으로, 날짜 선택·메뉴 이동, Mock 표시 | 모바일 폭에서 핵심 탐색 가능, 가로 넘침·겹침 없음, 예시/실제 구분 |
| 3. 식단 실제 연동 | 공식 출처 조사, Playwright 수집, 정제·검증, DB 저장, 수동 명령, 화면 연결 | 실제 식단 수집·조회, 재수집 중복 없음, 실패 시 기존 데이터 보존 검증 |
| 4. 학사일정·공지·홈 통합 | 일정·공지 수집과 조회, 홈 연결 | 원문·날짜·수집 시각 추적 가능, 한 수집원 실패·빈 데이터에서도 화면 동작 |
| 5. PWA·자동 갱신 | 매니페스트·아이콘·서비스 워커, 오래된 데이터 표시, 주 1회 수집 설정 | 지원 브라우저에서 설치·갱신 확인, 설정 작성과 실제 스케줄 등록·실행 확인 구분 |
| 6. Ubuntu 배포 | Nginx → Gunicorn → Django → DB, 크롤러, 로그·정적파일·재시작·백업, HTTPS | 실제 서버에서 외부 HTTPS 접속 검증. 서버가 없으면 설정·절차만, 배포는 미완료로 기록 |
| 7. 스마트폰 실사용 검증 | 학교/집 Wi-Fi, LTE/5G, QR코드, 주요 흐름 점검 | 실제 기기 확인과 PC 확인 구분, 문제와 수정 결과 기록 |
| 8. 기획서·개선 제안서 | 검증된 구현 기반 문서 | 미구현·미수행 검증을 성과로 쓰지 않음 (사용자 요청 시 진행) |

## 계정 기능의 향후 방향 (미구현)

- Lolypoly 자체 DB에 사용자 정보 저장 (`accounts.User`)
- 학번은 프로필 정보이며 학번만으로 인증하지 않는다
- Django Session 기반, 약 30일 로그인 유지 검토
- 도입 시 HTTPS, Secure/HttpOnly/SameSite 쿠키, CSRF 적용

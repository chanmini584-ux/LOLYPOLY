# 시범 운영 가이드 (학생 20~30명 · 교수님 확인)

20~30명은 앱의 제한이 아니라 **사용 경험을 모을 목표**다. 피드백 20건 ≠ 서로 다른 20명이다. 방문 횟수를 사람 수로 세지 않는다.

## 1. 학생에게 줄 체험 과업 (각 1~2분, 같은 과업을 학교 홈페이지로도 해 보기)
1. 오늘 점심 메뉴를 찾아보세요.
2. 내 과정의 이번 달 학사일정에서 가까운 일정을 찾아보세요.
3. 가장 최근 공지를 열어 공식 원문까지 가 보세요.
4. 마지막으로 의견 보내기에서 한두 줄 남겨 주세요.
(선택) 홈 화면에 추가해 보세요.

의견 질문 3개: ① 유용했던 기능 ② 막히거나 불편했던 점 ③ 다시 사용할 이유 또는 원하는 개선. 이름·학번·전화번호는 받지 않는다.

## 2. 수집 항목·목적·보관 (앱 안 안내 문구와 동일)
- 항목: 적은 의견, 제출 시각, (선택) 참여 코드, 도배 방지용 접속주소 해시(되돌릴 수 없음).
- 목적: 서비스 개선과 교수님께 드리는 시범 결과 보고.
- 보관: 초기 운영안은 **시범 종료 후 30일**. 적용 전 확인 필요(미확정). 기존 데이터를 일괄 삭제하는 정책은 실행하지 않았다.
- 반복 응답 구분: 배부 때 참여 코드(예: `A01`~`A30`)를 구두로 나눠 주고 선택 입력하게 하는 방법을 제안한다. 강제하지 않는다.

## 3. 사용 통계
이번 단계는 기능별 집계 대신 서버 접속 로그(`journalctl -u lolypoly-web`)의 경로별 요청 수와 수집 상태만 본다. 테스트 트래픽(개발자 접속)은 분리해서 센다. 측정 전에는 시간 절감·만족도·재방문 수치를 만들지 않는다.

# 오류 이력

발견한 오류를 수정 전에 등록하고, 같은 ID에서 조사·수정·검증 결과를 갱신한다.
상태: **접수 → 조사 중 → 수정 완료·검증 대기 → 해결**. 보류 시 이유·재개 조건을 적고 재발하면 같은 ID를 재개한다.
코드 수정과 운영 배포 확인은 분리한다. 문서 기록만으로 자동 로그 수집·보관이 구현된 것은 아니다.
날짜는 Asia/Seoul, 키·토큰·쿠키·개인정보·키가 포함된 URL은 기록하지 않는다.

## ERR-001

- **제목 / 영향:** TAGO 호출 집중으로 초당 한도 초과. 같은 키를 쓰는 실제 서버 버스 조회까지 잠시 제한됨.
- **발견일 / 환경 / 버전:** 2026-11-07, 홈 버스 기능 개발·실제 TAGO 연동, 버전 도입 전. 발생 SHA 미확인.
- **상태:** 수정 완료·검증 대기.
- **재현 기록:** 이전 구현에서 홈을 열 때 18개 노선 위치를 동시에 요청. 기대는 빠른 도착정보 표시, 실제는 7~15초 지연 및 `LIMITED_..._PER_SECOND_EXCEEDS_ERROR`. 현재 운영 키에 부하를 주어 재현하지 않는다.
- **근거 / 확인된 원인:** `PROGRESS.md` 학교 버스 2단계, `DECISIONS.md` D-042. 동시 다수 호출이 초당 제한을 넘음. 일일 한도 소진과 구분.
- **수정:** 홈을 정류소 도착정보 1회·1분 캐시로 변경, 위치 조회 순차 호출·한도 발생 시 중단·안내 분리. 관련: `campus/bus.py`, `campus/tago.py`, `campus/views.py`. 기준 소스 `2ad2350`에 포함, 최초 수정 SHA는 미확인.
- **과거 검증:** 2026-11-07 검사 이슈 0·마이그레이션 변경 없음·테스트 81개 통과 기록. 실제 도착정보 API 응답 확인, 당시 학교 도착 예정 0건으로 버스 표시는 가짜 응답 검증.
- **남은 확인 / 종료 기준:** 실제 버스가 학교 정류장으로 접근할 때 표시와 운영 로그를 확인하고 키의 현재 초당·일일 한도를 기록한 뒤 상태 갱신.

## ERR-002

- **제목 / 영향:** 무료 호스팅이 깨어나는 동안 대기 화면이 보임. 대기 HTML이 정상 홈으로 저장되면 오프라인에서도 해당 화면을 볼 수 있음.
- **발견일 / 환경 / 버전:** 2026-11-09, 공개 Render 관찰 + 로컬 프록시 흉내 환경, 버전 도입 전.
- **상태:** 수정 완료·검증 대기.
- **재현 기록:** 대기 HTML을 반환하는 프록시를 통해 방문 후 오프라인 전환. 기대는 마지막 앱 화면, 이전 서비스 워커는 대기 화면을 저장. 8초 지연 응답에서도 저장 화면 전환을 검증. 실제 Render 대기 화면 관찰은 약 45초였으나 HTTP 상태 코드는 미확인.
- **근거 / 확인된 원인:** `PROGRESS.md` 시험 사용 전 개선, D-043·D-044. 흉내 환경에서 앱/대기 HTML 식별 부재를 재현. 실제 Render도 동일하게 캐시됐다고 단정하지 않는다.
- **수정:** 앱 응답 헤더 확인, 헤더 없는 HTML 저장 금지, 4초 지연 시 같은 경로 저장 화면 우선. 버스 수집을 시작 뒤로 이동. 관련: `campus/middleware.py`, `templates/pwa/sw.js`, `Dockerfile`. 수정 커밋 `2ad2350`.
- **과거 검증:** 2026-11-09 Django 검사 0·마이그레이션 변경 없음·89개 테스트 통과, 390px 서비스 워커 흉내 환경 13개 항목 통과 기록.
- **남은 확인 / 종료 기준:** 해당 커밋 운영 반영 후 실제 Render 대기 응답 상태·헤더, 기존 설치자 업데이트·오프라인 동작을 실기기에서 확인. 운영 시작 시간 개선 폭은 미측정.

## ERR-003

- **제목 / 영향:** 공개 주소가 main 최신 홈이 아니며 `/bus/nearest/` 404, 다음 주 식단 없음.
- **발견일 / 환경 / 버전:** 2026-11-09, `https://lolypoly-x7a3.onrender.com`, 배포 SHA 미확인. 마지막 수집 11/7 17:24로 기록됨.
- **상태:** 접수. 2026-11-10 현재 운영 상태는 재확인하지 않음.
- **재현 기록:** 기존 점검에서 공개 홈과 main 소스를 비교하고 도착정보 경로·11/16 이후 식단을 확인. 기대는 의도한 커밋과 최신 공개 식단, 실제는 이전 화면·경로 404·식단 없음.
- **근거 / 원인:** `PROGRESS.md` 시험 사용 전 개선. 소스·배포 불일치 관찰됨. 배포 미실행/실패/설정 등 근본 원인은 미확정. 이미지 내 수집 DB의 갱신은 별도 빌드가 필요함.
- **수정 / 관련 파일·커밋:** 운영 조치 대기. 자동 갱신 기능은 미구현. 앱 파일을 임의 변경하지 않음.
- **검증:** 이번 작업에서 재실행 없음. 기존 기록만 이관.
- **남은 확인 / 종료 기준:** 배포된 SHA와 성공/실패 로그를 확인하고 의도한 소스 반영 → 필요 시 캐시 없는 빌드로 재수집 → 공개 홈·`/bus/nearest/`·해당 주 식단 확인. 운영 로그에서 키는 제거하고 결과만 기록.
